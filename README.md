# Tic-Tac-Toe

A modern, responsive Cyberpunk-themed Tic-Tac-Toe game featuring three AI difficulty levels and live score tracking.

## Features
- **AI Difficulty Modes**:
  - **Easy**: AI selects random available moves, ideal for beginners.
  - **Medium**: AI uses smart heuristics—taking winning moves and blocking player threats while remaining beatable with strategic tactics.
  - **Hard**: Powered by the **Minimax** algorithm, providing an unbeatable AI opponent that plays optimal moves every turn.
- **Scoreboard**: Tracks Player (X) wins, Ties, and AI (O) wins across rounds.
- **Visuals**:
  - Cyberpunk violet & cyan glow aesthetics with animated background lighting.
  - Winning pattern highlight with pulsing animation.
  - Responsive design optimized for desktop and mobile displays.

## How to Play
Open `index3.html` or `index.html` in any web browser.
